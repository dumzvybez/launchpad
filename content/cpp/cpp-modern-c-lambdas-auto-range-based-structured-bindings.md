### Key Concepts

- A lambda generates an unnamed functor class; captures become members; operator() is the call.
- `[=]` captures all used variables by value; `[&]` by reference; `[x]` / `[&x]` selectively; `[x=expr]` init-capture (move into the lambda).
- `auto` deduces like template T: top-level const and reference are stripped; use `const auto&` to read without copy.
- Structured bindings `auto [a, b] = pair_or_tuple_or_struct` decompose aggregates cleanly (C++17).
- `auto` in a lambda parameter list (C++14) makes it a generic lambda — basically a template operator().
- std::function type-erases any callable; convenient but costs an indirection (and often a heap alloc) per call.
- A `mutable` lambda can modify its by-value captures (otherwise operator() is const).

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    int factor = 3;
    std::vector<int> v{1, 2, 3, 4};

    std::for_each(v.begin(), v.end(), [factor](int& x) {       // by value
        x *= factor;
    });

    int sum = 0;
    std::for_each(v.begin(), v.end(), [&sum](int x) {          // by reference
        sum += x;
    });
    std::cout << sum;   // (3+6+9+12) = 30
}
```

### Common Pitfalls

- `[&]` capturing a local by reference and outliving it — the classic dangling-capture bug; the lambda holds references to dead stack frames. Capture by value or extend lifetime.
- `auto x = vector_of_bools[0];` — auto strips the proxy reference; you get a copy, not a reference. Use `auto&` or `decltype(auto)`.
- Forgetting `mutable` on a by-value lambda that wants to modify captures — the operator() is const by default; mark mutable.
- std::function in a hot path — type erasure costs an indirection and possibly a heap alloc; use auto or a template parameter when possible.
- Generic lambdas deducing different types per call — `[](auto a, auto b)` allows `a + b` for any compatible types, but mismatches cause hard error messages at the call site.

### Real-World Applications

- Cppcheck and clang-tidy use lambdas heavily for AST traversal callbacks.
- Unreal Engine's gameplay code uses lambdas for delegate binding (with a custom capture system that integrates with the engine's reflection).
- WebKit's parser uses lambdas for state-machine transitions, capturing local context cheaply.
- Bloomberg's bdlma allocators expose lambda-based scoped allocators for arena-style temporaries.

### Interview Questions

- 1. What is a lambda in C++? — An unnamed functor class generated by the compiler; captures become members and operator() is the call.
- 2. What does `[=]` capture? — All used variables by value (copy); `[&]` captures by reference; selective captures are `[x]`, `[&x]`, and init captures `[x=expr]`.
- 3. What is the difference between auto and decltype? — auto deduces like template T (strips top-level const/ref); decltype(expr) yields the declared type of expr, preserving references. decltype(auto) (C++14) combines both.
- 4. What is a generic lambda? — A lambda with `auto` parameters (C++14); it's basically a template operator() that can be called with different types.
- 5. Why is std::function slower than a lambda directly? — std::function type-erases any callable, costing an indirection (and often a heap alloc) per call; auto or templates preserve the static type and inline.
